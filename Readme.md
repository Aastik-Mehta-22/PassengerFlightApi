# Passenger Flight API

A learning-focused ASP.NET Core Web API for managing passenger flight data.

## Tech Stack

* C#
* .NET 10
* ASP.NET Core Web API
* Git & GitHub

## Project Goal

This project is being developed to understand the complete software development lifecycle, including:

* REST API development
* CRUD operations
* Database integration
* Automated testing
* Git & GitHub workflows
* CI/CD pipeline
* Build and deployment processes
